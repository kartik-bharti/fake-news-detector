# Fake News Detector

A Machine Learning web app to detect REAL vs FAKE news.

### Tech Stack
- Python, Flask, Scikit-learn, Pandas
- TF-IDF Vectorizer + Logistic Regression
- Deployed on Render

### Live Demo
https://fake-news-detector-x43y.onrender.com

### How to Run Locally
1. pip install -r requirements.txt
2. python app.py

### How it works
User enters news text > Model predicts > Shows REAL or FAKE
